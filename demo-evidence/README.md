# Demo evidence workspace

This directory is the staging location for SIH demonstration screenshots and the backup recording. It
contains instructions only until the team captures and reviews the evidence on the presentation laptop.

## Required filenames

1. `01-profile-categories.png`
2. `02-field-classifications.png`
3. `03-sanitized-zero-match.png`
4. `04-accepted-plan.png`
5. `05-local-fill.png`
6. `06-submission-boundary.png`
7. `07-full-flow.mp4`

Capture the exact states described in `TEST_MATRIX.md`. Use the built-in fictional demo profile only.

## Privacy review before sharing

- Confirm no real name, email, phone, address, DOB, Aadhaar, PAN, password, OTP or API key is visible.
- Confirm unrelated tabs, bookmarks, notifications, accounts, terminal history and desktop files are cropped.
- Confirm the payload and plan show typed categories rather than private values.
- Confirm the submission dialog contains only form name, filled count and critical category names.
- Have a second team member review every artifact.

Do not commit unreviewed media. Large recordings should be kept in the team submission storage rather
than Git unless the team has deliberately configured Git LFS.
